# App Privacy (App Store Connect › App Privacy) — NEXUS 0.1.6
Tracking: NO (no data used to track across other companies' apps/sites). No third-party ads/analytics.

| Data type | Collected | Linked to user | Purpose |
|---|---|---|---|
| Precise Location | Yes | Yes | App Functionality (attendance, work-hours location trail) |
| Photos or Videos (selfies, attachments) | Yes | Yes | App Functionality |
| Name | Yes | Yes | App Functionality |
| Email Address | Yes | Yes | App Functionality |
| Phone Number (optional, profile) | Yes | Yes | App Functionality |
| User ID | Yes | Yes | App Functionality |
| Device ID (push token, device model) | Yes | Yes | App Functionality |
| Other User Content (tasks, chat, reflections, requests, files) | Yes | Yes | App Functionality |
| Crash Data / Performance / Usage analytics | No (none collected by NEXUS itself) | — | — |

Change from 0.1.5: **Precise Location** is now collected in the background during working hours
(check-in → check-out), not only at the moment of check-in — keep it declared as App Functionality.
