NEXUS is the internal workspace app for employees of Z Networks (PATS Group): tasks, projects, chat, requests and a read-only view of attendance. Accounts belong to a company workspace; the demo account below is in a separate demo workspace with no real company data.

Demo account: apple.review@znetworks.id - password: (same as the previous submission)

THE MAC APP
This is the same app as the iPhone/iPad version (Mac Catalyst, same version 0.1.6 build 13). The last Mac release was 0.1.1, so this update brings the Mac up to the phone.

ATTENDANCE ON THE MAC IS READ-ONLY
Checking in needs a selfie with a liveness check and the phone's location, so the Mac shows a card saying attendance is done on the phone. Everything that reads attendance works on the Mac: today's status, the crew board, reflections and requests. The Mac app does not use location at all and never tracks it.

HOW TO TRY IT
1. Sign in with the demo account.
2. Home: tasks, projects, daily agenda. Widen the window to see two or three columns.
3. Attendance > New request: file a request (for example Annual leave: click the first day, then the last).
4. Z Vault: upload a file and create a share link.
5. Ticket or Messages: "Take a photo" opens the Mac's camera.

CAMERA: photos for chat, tickets and requests, only when the user clicks "Take a photo". PHOTOS/FILES: attaching files the user picks. NOTIFICATIONS: approvals, reminders and announcements.

Accounts can be created in the app with a workspace code and deleted in Tuning Room > Delete account.
