# Screenshots

The images the root [README](../../README.md) shows. They are captured from the fictional **Demo Studio**
workspace (`scripts/seed-demo-workspace.ts`, signed in as `demo.owner@example.com`) with the UI tour
scripts, so no real person, company or record ever appears in them.

| File | Surface | Captured with |
|---|---|---|
| `web-desktop.png` | Web, desktop browser | `apps/ios/scripts/ui-tour.sh` (web) |
| `web-mobile.png` | Web, phone-width browser | `apps/ios/scripts/ui-tour.sh` (web) |
| `iphone.png` | iPhone | `apps/ios/scripts/ui-tour.sh` (iOS) |
| `ipad.png` | iPad | `apps/ios/scripts/ui-tour.sh` (iPad) |
| `mac.png` | Mac | `apps/ios/scripts/ui-tour.sh` (Mac) |
| `android.png` | Android phone | `apps/android/scripts/ui-tour-android.sh` |

Before adding one:

- Seed or refresh the demo workspace first, so dates look current.
- Check that nothing outside Demo Studio is visible: no other workspace in the switcher, no real names,
  emails, addresses or notifications.
- PNG, light appearance, no device frame; keep each file under about 1 MB.

When the files are here, uncomment the image grid in the root README's Screenshots section.
