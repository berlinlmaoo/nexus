R-16 route pairs include the green field/button snapshot `5aaa30c7` and later final-app recaptures. Earlier after-images precede R-18; violet checked-control acceptance is documented separately. The image pairs show either the enclosing native destination or a labelled production-component mount. A pair is not a claim that every conditional dialog on that destination was opened. Component mounts use the real composables, normal DEV reads where applicable, and inert callbacks for presentation-only data; Login retains its approved light appearance. OAA-only controls, legacy unmounted code and unsubmitted conditional flows remain explicitly identified.
