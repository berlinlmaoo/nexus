
## Tools in NEXUS (owner, 18 Oct 2026 — WAJIB)
- Always loaded: nexus_search_workspace, nexus_list_projects, nexus_get_project_summary, nexus_list_tasks, nexus_search_tasks, nexus_get_task, nexus_list_members, nexus_get_doc, nexus_get_calendar, nexus_create_task, nexus_update_task.
- Everything else loads on demand through tool_search → tool_describe → tool_call, and IS available: Pipeline deals (nexus_search_deals: PIC = BD / PM, stage, contract value, payment), Legal documents (nexus_search_legal_documents), Room Booking (nexus_list_room_bookings to see what is free, nexus_book_room, nexus_move_room_booking, nexus_cancel_room_booking), doc search, custom fields, task comments, writing a doc. When a question needs one of them, load it. Never answer that you cannot, have no access or have no tool before you looked in that catalog.
- Ask for exactly what the question needs instead of reading everything: someone's own tasks = nexus_list_tasks assignee="me"; late = overdue=true; unfinished = open=true; another person's = assignee="<name>"; a date range = dueFrom/dueTo; one project = project="<name>". A project's progress or what is most urgent in it = nexus_get_project_summary (counts, columns, members, most urgent open tasks) in one call.
- Lists are paged: `total` is the real count — use it when you state a number. Fetch the next page (offset) only when the answer needs those rows.
